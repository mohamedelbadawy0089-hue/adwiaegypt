🎯 دليل اختبار نظام الموظفين الجديد

✅ تم تطوير النظام بنجاح! الآن يمكن لكل مخزن إضافة موظفين متعددين بنفس الإيميل

📋 خطوات الاختبار

1️⃣ تسجيل مخزن جديد
  1. افتح صفحة register.html
  2. أدخل بيانات المخزن (اسم المخزن، التليفون، المحافظة، الإيميل، الباسورد)
  3. اضغط "تسجيل"
مثال:
الإيميل: test@warehouse.com
الباسورد الرئيسي: admin123
2️⃣ تسجيل دخول المدير
  1. افتح صفحة login.html
  2. أدخل الإيميل: test@warehouse.com
  3. أدخل الباسورد: admin123
  4. اضغط "دخول"
  5. سيتم توجيهك إلى admin-dashboard.html
3️⃣ إضافة موظفين
  1. في صفحة admin-dashboard.html، انتقل لقسم "إدارة الموظفين"
  2. أضف موظف أول:
    الاسم: أحمد محمد
    الباسورد: ahmed2024
  3. أضف موظف ثاني:
    الاسم: محمد علي
    الباسورد: mohamed2024
  4. أضف موظف ثالث:
    الاسم: سارة أحمد
    الباسورد: sara2024
4️⃣ تسجيل دخول الموظف
  1. سجل خروج من حساب المدير
  2. افتح صفحة login.html
  3. أدخل الإيميل: test@warehouse.com (نفس إيميل المخزن)
  4. أدخل باسورد الموظف: ahmed2024
  5. اضغط "دخول"
  6. سيتم توجيهك إلى telesales.html
5️⃣ اختبار صلاحيات الموظف
  1. في صفحة telesales.html، ستجد زرين فقط:
    • 🏥 الصيدليات
    • 📦 الأوردرات
  2. جرب إضافة صيدلية جديدة
  3. جرب إنشاء أوردر
  4. لاحظ أن الموظف لا يمكنه الوصول لإدارة المنتجات أو رجال الدليفري

📊 جدول المقارنة

الميزة المدير (Admin) الموظف (Employee)
إدارة المنتجات ✅ نعم ❌ لا
إدارة الصيدليات ✅ نعم ✅ نعم
إدارة الأوردرات ✅ نعم ✅ نعم
إدارة رجال الدليفري ✅ نعم ❌ لا
إدارة الموظفين ✅ نعم ❌ لا

  • جميع البيانات محفوظة في localStorage و IndexedDB
